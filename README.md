## 📖 О проекте

Полнофункциональная образовательная платформа, разработанная для репетитора по химии. Проект включает публичную часть сайта, личный кабинет ученика и мощную админ-панель с возможностью управления учебным процессом.

### 🎯 Ключевые возможности

#### 🌐 Публичная часть

- **Главная страница** с hero-секцией и карточками преимуществ
- **Страницы**: Обо мне, Услуги, Блог, Отзывы, Контакты
- **Модальная авторизация/регистрация** с валидацией через Zod
- **Политика конфиденциальности** с управлением согласиями (ФЗ-152)
- **SEO-оптимизация**: JSON-LD schema, sitemap, robots, Open Graph

#### 👤 Личный кабинет ученика

- 📅 Персональное расписание занятий
- 📝 Домашние задания с возможностью загрузки решений
- 📚 Учебные материалы (теория, видео, задачи)
- 📊 Отслеживание прогресса обучения
- ⚙️ Настройки профиля и управление согласиями

#### 🛡️ Админ-панель

- 📅 **Сводное расписание** всех учеников на неделю с почасовой разбивкой
- ➕ **Добавление уроков** с привязкой к ученикам
- 📝 **Назначение домашних заданий**
- 👁️ **Режим имперсонации** — просмотр кабинета любого ученика от его имени
- 📋 **Модерация отзывов**
- ⭐ **Добавление отзывов** вручную
- 👥 **Управление пользователями**

## 🛠️ Стек технологий

| Категория          | Технология                                    |
| ------------------ | --------------------------------------------- |
| **Frontend**       | Next.js 15 (App Router), React 19, TypeScript |
| **Стилизация**     | Tailwind CSS, shadcn/ui, Geist Fonts          |
| **Backend**        | Next.js API Routes, Server Actions            |
| **База данных**    | PostgreSQL, Prisma ORM                        |
| **Аутентификация** | NextAuth v5 (Auth.js) с JWT-стратегией        |
| **Валидация**      | Zod, react-hook-form                          |
| **Уведомления**    | Sonner                                        |
| **Иконки**         | Lucide React                                  |
| **Дата/время**     | date-fns                                      |
